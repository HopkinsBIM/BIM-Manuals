Clearing Disk Space IT / BIM Team · July 2026

Our standard hard-drive specification is currently 2 TB for desktops and 1 TB for laptops, but many older machines have less. Through careful management they can still be used successfully. Revit in particular is hungry for space — there are several areas to keep an eye on if you are running short.

How much space do I have?

Select This PC in Explorer, or right-click on C:/ and choose Properties to see your current disk usage at a glance.

Right-click C:/ → Properties to check disk space
Section 1

General Disk Cleanup

1

Documents

Check locally saved files and remove unneeded ones. Any business-critical information should be stored on the servers, not on your local drive.

2

Downloads & Recycle Bin

Clear your Downloads folder and empty the Recycle Bin. These are often the quickest wins.

3

Windows Disk Clean-up

Search for Disk Clean-up in the task bar, or right-click C:/ → Properties → Disk Clean-up. It will show what can be safely removed. Check the categories as appropriate and select OK.

Windows Disk Clean-up dialog
4

OneDrive — Free Up Space

Folders and files saved on disk (rather than cloud-only) are shown with a green tick. If you don't need immediate offline access, right-click and choose Free Up Space to keep them cloud-only.

Section 2

Clearing Disk Space for Revit

These steps apply specifically to Revit on virtual desktops.

1

Clear C:\Autodesk

Autodesk stores installers here to assist with repair installs, but they are not generally needed — we have the installers centrally in IT. Files in this location can total up to 50 GB and can be safely removed.

2

Remove Old Revit Local Files

By default Revit saves local files into Documents. Create subfolders for each version for ease of management:

%USERPROFILE%\Documents\Revit 2026 Local

To check your local file path: R → Options → Default path for user files. Once changes are synced to central, local files are no longer necessary — delete them if you're not actively using the model.

3

Free Up Space in Desktop Connector (ACC / BIM 360 only)

Desktop Connector may download linked files for ease of access. Free up space by right-clicking on a project listed in This PC → Autodesk Docs and selecting Free Up Space.

⛔ Mandatory: Do not directly delete files in Explorer within ACC / BIM 360 — they will be deleted from the cloud as well.

Right-click project → Free Up Space
4

Clear Collaboration Cache (ACC / BIM 360 only)

With Revit closed, delete all files from these four locations (## = Revit year version):

C:\Users\%username%\AppData\Local\Autodesk\Revit\Autodesk Revit 20##\CollaborationCache\
C:\Users\%username%\AppData\Local\Autodesk\Revit\PacCache\
C:\Users\%username%\AppData\Local\Autodesk\Revit\Autodesk Revit 20##\CefCache
5

Clear TEMP

Applications including Revit use TEMP for temporary files. With as many applications closed as possible, type %TEMP% into an Explorer window, press Ctrl+A to select everything, then delete. Files needed by active applications will be skipped.

Section 3

Deeper Clean

If you're still struggling for space after the steps above, check these areas.

1. Remove Unused Software

Adobe: Check Creative Cloud and remove older versions if not needed.

Autodesk: Each year brings new versions of Revit, AutoCAD etc. Consider whether you need all installed versions. To remove, email IT.

Twinmotion: Consumes about 18 GB per version. If you no longer need a version, email IT to request removal.

2

Outlook PST

If your inbox is very large it will consume disk space. Check with IT about the archive policy on your account.

3

WinDirStat Analysis

Get IT to run WinDirStat to analyse used space and identify what can be targeted for removal. This gives a visual treemap of your entire disk to pinpoint the largest consumers.

Keep It Clean

Running low on disk space impacts Revit performance, sync reliability, and export quality. Make these checks a regular part of your workflow — a quick cleanup every few weeks prevents problems before they start. For persistent issues, contact IT.
