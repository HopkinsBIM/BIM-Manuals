Creating a New Project File

1

Open Revit — launch Revit 2026 (or the office-standard version).

2

On the Revit start screen, click New… under the Models section (left panel). The New Project dialog will appear.

Revit 2026 start screen — click New… (highlighted in green) under Models in the left panel

3

In the New Project dialog, click Browse… next to the Template file field. Do not use the default Construction Template.

New Project dialog — click Browse… (highlighted in green) to navigate to the HA template location

⚠ Caution: All new Revit files must be created using the latest HAD RVT Template. Never start from a blank Revit template or from a previous project file.

4

In the file browser, navigate to the server template location:

L:\04 BIM STANDARDS\02-Source Files and Templates\01-Revit Template
5

Select the template file: HAD_Revit Project Template_V01(Base 2024).rte and click Open.

6

Back in the New Project dialog, ensure the Project radio button is selected under "Create new" — then click OK.

Template field shows HAD_Revit Project Template_V01 — ensure "Project" is selected, then click OK

Saving a Model to Autodesk Construction Cloud (ACC)

Revit models can be saved directly to ACC using Revit’s built-in cloud collaboration tools. This enables real-time worksharing via the cloud without relying on a VPN or server connection. Use this workflow when collaborating with remote team members or external consultants.

Prerequisite: You must have an active Autodesk account with access to the relevant ACC project, and the project must have Revit cloud worksharing enabled by the project admin in ACC.

Go to File → Save As → Cloud Model, sign in with your Autodesk account, name the file following the HA naming convention (e.g. PXXX-HAD-M3-A-000001) and click Open. Revit will upload and convert it to a cloud-workshared central file.

File menu → Save As → Cloud Model — saves the current model to ACC

Once uploaded, other team members open the model from ACC via Revit Home → Autodesk Forma. Synchronise using Collaborate tab → Synchronize with Central — same command as server-based. Changes push directly to ACC with no VPN required.

8

Update Project Information (Manage tab → Project Information) with the correct project name, number, address, client name, and project status before sharing the file with the team.

2

Creating a Central (Workshared) File

Create a central file only when 2 or more users will collaborate on the same model, or when Worksets are needed to divide the model into sections.

Steps to Enable Worksharing

1

Open the saved project file. Go to the Collaborate tab in the Revit ribbon.

2

In the Manage Collaboration panel, click Worksets. A prompt will appear asking to enable worksharing — click OK.

Collaborate tab → Manage Collaboration panel → Worksets

3

In the Worksets dialog, the default worksets (Shared Levels and Grids, Workset1) are created automatically. Rename and add worksets as per the HA standard workset list in Section 4 below. Click OK when done.

⚠ Caution — Local files: When opening a central file, always open it via the Revit application (never via Windows Explorer) and select "Create New Local". Local files should be stored in your C: drive and deleted weekly. Never save local files to the server.

4

Go to File → Save As → Project. In the Save As dialog, click Options… to open the File Save Options dialog — configure the settings in the table below before saving as a central file.

Standard Worksets to Create

After creating a new file from the HAD template, create the following Worksets as a minimum:

00_Shared_Level_and_Grids
Levels and Grids in Geometry Models
00_Reference_Planes
All reference planes in Geometry and Sheets models
00_Enscape_Assets
All Enscape / visualisation elements
01_Content_HA_Arch
All Architectural and Interior design elements
02_Content_HA_Structure
All Structural placeholder elements
02_Content_HA_MEP
All MEP placeholder elements

Refer to the HA BIM Manual for the full Workset list, including link and specialist discipline worksets.

Synchronising Central Files — Recommended Procedure

Follow this sequence every time you synchronise with the central file. Do not skip steps — each ensures other team members can access your changes and that the model stays clean.

1

Return to Splash Page

Navigate to the Landing Page view before syncing

2

Save Local File

Ctrl+S to save your local copy first

3

Reload Latest

Load latest changes from other users

4

Sync & Modify Settings

Use default sync settings — do not change options

5

Relinquish All Mine

Release ownership so others can edit your elements

Sync frequency: Synchronise at minimum every 2 hours, or whenever completing a significant task. Always synchronise before leaving for the day.

General Drawing Advice

"Managing a drawing can be thought of as engineering a high-speed car — it needs to be elegant but more importantly incredibly efficient. Never draw more than is needed, and always keep models and drawings as light and clean as possible."

Model Performance Guidelines

!

Avoid over-complicated components; beware of web library families and manufacturer components

!

Check warnings regularly and always aim to resolve them, especially duplicate object warnings

!

Delete unused views; if created for checking, delete afterwards. Purge unused families regularly

!

Always Link CAD files instead of importing; avoid linking large images or CAD files where possible

!

Model In-Place families to a minimum — avoid for elements that repeat across the project

!

Prefer Families over Groups; groups behave unexpectedly with hosted elements (doors, furniture)
