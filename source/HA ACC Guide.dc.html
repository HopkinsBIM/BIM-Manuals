ACC Drawing Validation – OCR Guide Prashanth Perumal · Version 1.0

About this guide: Autodesk Construction Cloud (ACC) is an integrated platform for the construction industry enabling seamless collaboration and document management. This guide outlines step-by-step procedures for extracting pages and attributes from drawings using ACC's Optical Character Recognition tools to ensure drawing contents are accurate, complete, and compliant with project requirements.

1

Preparation: Prerequisites & Setup

Licensing & Technical Requirements

Before beginning extraction and validation, ensure the following are in place:

Access to Autodesk Construction Cloud with appropriate permissions for Docs

Drawing files uploaded to the ACC project in PDF or DWG format

Knowledge of required attributes: sheet number, revision, title, author, date

Familiarity with the ACC user interface and project folder navigation

Permissions note: Ensure you have the correct role permissions in ACC Docs to access the title block extraction and attribute capture features before proceeding.

2

Extracting Pages & Attributes: Step-by-Step

1

Locate and Access the Drawings

  • Log into your Autodesk Construction Cloud account
  • Navigate to the Docs module and locate the Drawings section
  • Browse to the folder containing the drawing files you wish to validate
2

Extract Pages from Multi-Page Drawings

  • Select the drawings you wish to validate
  • Right-click and select Extract pages and attributes
  • At the top of your screen, select Capture title block
3

Configure Attribute Capture

  • On the right-hand side, select the required attributes from the Add attributes option
  • Draw their corresponding capture boundaries in the reference title block using the Edit capture area button
  • Select Capture all pages to apply the configuration across the drawing set
4

Review & Validate

  • Review whether all required attributes have been correctly captured
  • Make corrections to capture areas where OCR has misread data
  • Hit Save to confirm the capture configuration

Export the Drawing Log for QC

  • Export the drawing log in .CSV format to carry out final Quality Control checks
  • Cross-reference extracted attributes against the project drawing register
  • Flag any discrepancies to the project BIM Lead for resolution
3

Key Attributes to Validate

Attribute
What to Check
Sheet Number
Matches project naming convention (e.g. 2449D-HAD-DW-A-103001)
Revision
Correct revision letter/number (P01, P02, C01 etc.) matches drawing register
Drawing Title
Accurately reflects the content and matches the drawing register entry
Author / Drawn By
Initiator code matches the responsible team member or sub-consultant
Issue Date
Format YYYY-MM-DD as per HA naming standards; matches transmittal date
Scale
Stated scale is appropriate for the drawing type and sheet size

Quality Assurance Note

Regular use of ACC's OCR validation workflow ensures consistent drawing quality across the project. Issues identified during extraction should be corrected at source in the Revit model before re-issuing. For tool support or permissions issues, contact prashanth.p@hopkins.ae.
