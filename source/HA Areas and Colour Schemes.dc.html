Areas, Area Plans & Colour Schemes Prashanth Perumal · Version 1.0 · June 2026

Area Plans in Revit are separate from Rooms — they measure space at the floor level using boundary lines you draw, and they belong to a named Area Scheme (e.g. GFA, BUA, NSA, NIA, GIA). Colour Schemes are then applied to plans to visually communicate zoning, department, occupancy or any other parameter.

1

Creating a New Area Scheme

Create the scheme before drawing any area plans — each area plan is tied to a single scheme and cannot be changed after creation. Revit ships with two defaults: Gross Building and Rentable.

1

Go to Architecture tab → Area panel → Area drop-down → Area and Volume Computations.

Architecture tab → Room & Area panel → Area drop-down → Area and Volume Computations

2

Switch to the Area Schemes tab.

3

Click New to add a scheme. Name it using the Hopkins convention: HAD_NIA, HAD_GIA, HAD_Departmental. Add a short description so other users understand its purpose.

Area Schemes tab — Click New, name using HAD_ prefix, add description. Do not edit the default Gross Building scheme.

4

Click OK to save. The scheme is now available when creating Area Plans. Do not edit or delete the default Gross Building scheme.

2

Creating Area Plans

1

Go to Architecture tab → Area panel → Area Plan.

2

In the New Area Plan dialog, choose the Area Scheme (e.g. HAD_GFA) and select the level(s). Hold Ctrl to select multiple levels — Revit creates one Area Plan per level.

3

When prompted to auto-create boundary lines: choose Yes for Gross schemes (external wall face) and No for other schemes (draw manually to internal face).

4

New Area Plans appear under Views → Area Plans → [Scheme Name]. Rename them to match the project's view naming convention.

5

Draw area boundaries using Architecture → Area panel → Area Boundary. Boundaries must form fully closed loops — gaps cause "Area Not Enclosed" warnings.

Area panel — Area (place), Area Boundary (draw), Tag Area

6

Place areas using Architecture → Area panel → Area. One area per enclosed boundary. Rename each area immediately — do not leave them as "Area 1", "Area 2".

7

Tag areas using Annotate → Tag by Category or the Area Tag family directly. Tags display Area Name, Number, and Area value as standard.

Annotate → Tag by Category (single) · Tag All (all untagged)

3

Creating & Applying Colour Schemes

Colour Schemes visually code rooms or areas by any parameter (Name, Number, Comments etc.). They live in the project file and can be applied to multiple views. Each view can carry only one colour scheme per category.

1

With the target plan view active, go to the Properties palette → Color Scheme → Edit.

Properties palette → Color Scheme row — click the value field to open the Edit Color Scheme dialog

2

In the Edit Color Scheme dialog, choose the Category (Rooms or Areas — Areas are further split by scheme, e.g. "Areas (HAD_NIA)").

3

Click the Duplicate icon (bottom-left) to copy the default "Schema 1" and rename it (e.g. "HAD_GFA", "HAD_BUA"). Never edit the default schema directly.

4

Set the Colour By parameter — the parameter that drives the colour fill. Common choices are Name or Number.

5

Choose By Value (one colour per unique value) or By Range (colour bands for numeric values like Area). For categorical data always use By Value.

6

Set Visible, Color, and Fill Pattern per row. Use the office colour palette — do not pick arbitrary RGB values.

7

Click OK. Add a Colour Scheme Legend via Annotate → Color Fill Legend so the reader can interpret the colours.

8

To reuse a colour scheme on another view, set the Color Scheme property on that view to the same named schema — do not duplicate and re-edit.

4

Do's & Don'ts

Do's
Create the Area Scheme before drawing any area plans — schemes cannot be swapped on an existing plan without redrawing.
Name schemes, area plans and colour schemes using the HAD_ prefix so they're easy to identify in the Project Browser.
Draw area boundaries as fully closed loops; use Trim/Extend to clean up intersections. Do not overlap boundaries.
Use Gross schemes for external-face measurements and Net schemes for internal-face — keep them in separate area plans, never mix.
Duplicate the default Schema 1 before editing — the original stays clean as a fallback.
Add a Colour Scheme Legend to every colour-filled plan on a sheet — without it the reader cannot interpret the colours.
Audit area plans regularly using an Area Schedule to catch Not Enclosed or Redundant areas — delete them from the schedule.
Don'ts
Don't draw area boundaries on top of room separation lines — they serve different purposes and clutter the model.
Don't use Rooms when Areas are required (and vice versa). Rooms = enclosed volumes from walls; Areas = 2D extents from boundary lines.
Don't apply more than one colour scheme of the same category to a view — Revit only honours one Room scheme and one Area scheme per view.
Don't pick arbitrary RGB values for colour fills — always use the office colour palette for consistency across projects.
Don't edit the default Schema 1 — duplicate it first, otherwise other users opening the model lose their fallback.
Don't bake colours into the legend by manually overriding tag colours — let the colour scheme drive everything so updates propagate automatically.
Don't export coloured plans to PDF and re-colour in Illustrator — always update colours at source in Revit so the model remains the single source of truth.
