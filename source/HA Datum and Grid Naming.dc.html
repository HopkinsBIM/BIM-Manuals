Overview & Setup

At the start of each project, create a dedicated Revit file for Grids and Levels (named PXXX-HAD-M3-Z-000000.rvt). All disciplines Copy/Monitor grids and levels from this file. Any change to grids or levels must be coordinated through the BIM Manager before implementation.

Important: Never modify grids or levels in individual discipline models. All changes must originate in the dedicated Grids & Levels file and be propagated via Copy/Monitor.

Copy/Monitor Procedure

All discipline models must Copy/Monitor grids and levels from the dedicated M3-Z-000000 Grids & Levels file. This ensures all models share a common coordinate system.

1

Link the M3-Z-000000 Grids & Levels file into your discipline model

2

Go to Collaborate tab → Copy/Monitor → Select Link, then click the linked file

3

Select Copy from the ribbon, then click each grid and level to monitor. Click Finish when done

Revit will now monitor the linked grids/levels and alert you when changes occur in the source file — accept or reject as appropriate
