What is Bluebeam Studio?

Bluebeam Studio is a cloud-based collaboration platform integrated within Bluebeam Revu. It allows design consultants to host sessions, share and review design documents, and collaborate in real-time with project stakeholders. Studio Sessions enable multi-user interaction where participants can view and respond to markups immediately — ideal for managing complex design reviews and ensuring seamless communication across teams.

1

Getting Started

System Requirements

Before using Bluebeam Studio, ensure your setup meets these requirements:

OS
Windows or macOS
Software
Bluebeam Revu (licensed)
Connection
Active internet connection
Account
Bluebeam Studio account

Creating a Bluebeam Studio Account

  1. Open Bluebeam Revu and navigate to the Studio panel (icon on the left sidebar)
  2. Click "Sign In" — the Studio sign-in panel will open
  3. Click "Sign Up" if you don't have an account, enter your Bluebeam ID (email), create a password, and complete the required details
  4. Verify your email to activate the account before proceeding
2

Using Studio Sessions

Hosting a New Session
  1. In the Studio panel, click the + button and select "New Session"
  2. Enter a Session Name, add documents using the Add button
  3. Set Permissions (Save As, Print, Markup, Add Documents etc.) to control access
  4. Invite collaborators by sharing the session ID or email invitation
Joining a Session
  1. In the Studio panel, click + and select "Join"
  2. Enter the Studio ID provided by the session host and click OK
  3. Use the markup tools to annotate, comment, and make changes to documents
  4. All changes are auto-saved — Bluebeam records all activity for accountability
3

Best Practices

Session Naming

Use clear, consistent naming conventions for sessions. Prefix uploaded files with the date in YYMMDD format before uploading (e.g. 250625_Drawing_Review).

Permissions

Define permissions carefully. Restrict sensitive documents to authorised personnel and provide editing rights only when necessary.

Markup Layers

Use layers for different annotation types. Apply stamps for approvals and assign each user a specific colour for clearer design document reviews.

Regular Backups

Although Studio provides cloud storage, periodically download copies of critical design documents to your local project folder as a backup.

4

Advanced Features

Mobile Access

Revu is available on iOS and Android. Download the Bluebeam app to stay connected with Studio during site visits or remote meetings.

Markup Summary Reports

Export markup summaries to PDF or CSV to track review comments, responses, and outstanding actions across the team.

Custom Tool Sets

Build project-specific tool sets with predefined stamps, symbols, and text boxes to standardise the review process across all sessions.

For questions about Bluebeam Studio setup, session hosting, or permissions, contact the BIM Team at prashanth.p@hopkins.ae. Always use Studio Sessions for formal design review cycles — do not share raw PDFs via email for mark-up purposes.
