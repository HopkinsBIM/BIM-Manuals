Sheet & Model Structure Strategy BIM Team · June 2026

The split between Geometry Models and Sheets Models is not a one-size-fits-all decision. Getting it wrong early means either a bloated, slow model or fragmented files that are hard to coordinate. The correct structure depends on the project type and scale. The three scenarios below define the HA standard approach — if your project doesn't clearly fit one, liaise with the BIM Lead and Project Lead before setting up the model structure.

Scenario A
MSB / Tall Building — 3+ Floors & Basements
Structure
  • Multiple Geometry Models — split by discipline, zone, or podium/tower as required
  • One dedicated Sheets Model — all views, sheets, schedules, and 2D extraction live here
  • Geometry Models are linked into the Sheets Model
Why

A single combined model for a tall building will become unmanageably heavy. Separating geometry from documentation keeps each file focused and fast. The Sheets Model is the only file that produces PDFs and DWGs.

MSB / Tall Building

CD / SD: Geometry and Sheets reside in two separate models.
DD+ :  Geometry model shall be split into multiple files, each not exceeding 300 MB.
The Sheets model still stays separate.

Scenario B
Large-Scale Development — Villas, Townhouses & Clusters
Structure
  • Geometry and Sheets reside in the same model per building type (Office A, Office B etc.)
  • Each building type gets its own combined model file
  • No separate Sheets Model required
Why

Individual office / villa/townhouse models are typically small enough that combining geometry and sheets in one file is efficient. Splitting them adds unnecessary file management overhead for repetitive typologies unless individual files size is above 300 MB.

Per Building Type

CD / SD: Geometry + Sheets in one model.
DD+ : If file size is projected to exceed 300 MB, sub-disciplines can be split into separate linked models. Sheets remain in the Architectural model.

Scenario C
Neither of the Above — Unclear Scope

If the project doesn't clearly fall into Scenario A or B, do not assume a model structure. Set up a brief with the BIM Lead and Project Lead before creating any model files. The wrong model split at project start is expensive to unravel later.

Factors to discuss: anticipated model size, team size, stage deliverables, external consultant coordination, and whether ACC cloud worksharing is required.

Set Up Right from Day One

The model structure decision is made once, at project start, and is expensive to reverse. Use the decision guide above and always confirm with the BIM Lead and Project Lead before creating any model files. If you identify additional scenarios or have suggestions for future additions, please share them with the BIM Team.
